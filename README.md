# Facial Expression Classification

A basic deep learning project for classifying facial expressions from images.

## Overview

This project uses a convolutional neural network to classify facial expressions into different emotion categories. The model was developed as part of an undergraduate deep learning project and was also integrated into a simple web application for prediction.

## Contents

- `facial_expression_recognition.ipynb` — Jupyter Notebook containing the model development and classification workflow.
- `lenet_weights1.hdf5` — Saved model weights.
- `app.py` — Flask application for making predictions.
- `Procfile` — Deployment configuration.
- Sample `.jpg` images used for testing the application.

## Approach

The project follows a standard image-classification workflow:

1. Image preprocessing
2. Model training
3. Facial expression classification
4. Saving the trained model weights
5. Using the trained model in a simple web application
